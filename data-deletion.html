Threadscoupas 데이터 삭제 안내

시행일: 2026년 8월 23일 · 문의: redtain0807@gmail.com

Threadscoupas는 개인용 Windows 데스크톱 도구이며, 운영 데이터는 기본적으로 사용자의 PC에 저장됩니다.

앱에서 직접 삭제하는 방법

  1. Threadscoupas를 실행합니다.
  2. 설정 화면에서 해당 Threads 계정의 연결을 해제합니다.
  3. 필요한 경우 앱 종료 후 로컬 데이터 폴더의 데이터베이스와 설정 파일을 삭제합니다.
  4. 이미지 호스팅을 연결했다면 해당 저장소에서 본인이 올린 이미지 파일을 삭제합니다.

운영자에게 삭제를 요청하는 방법

앱에서 직접 삭제하기 어렵거나 삭제 확인이 필요한 경우, 연결한 Threads 계정의 사용자명과 삭제를 원하는 데이터 범위를 적어 redtain0807@gmail.com으로 요청해 주세요. 본인 확인에 필요한 최소 정보만 확인한 뒤, 운영자가 접근 가능한 범위의 데이터를 삭제하거나 삭제 방법을 안내합니다.

Meta Threads 연결 해제

Meta 계정의 앱·웹사이트 설정에서도 Threadscoupas의 연결 권한을 해제할 수 있습니다. 연결을 해제하면 이후 앱은 해당 계정으로 게시물 발행·인사이트 조회를 할 수 없습니다.

Data Deletion — English Summary

Most Threadscoupas data is stored locally on the user’s Windows PC. Users can disconnect their Threads account in the app and delete local database/configuration files. For assistance, email redtain0807@gmail.com with the connected Threads username and requested deletion scope. Users can also revoke the app connection in Meta account settings.
