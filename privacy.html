Threadscoupas 개인정보처리방침

시행일: 2026년 8월 23일 · 운영자: Lee Hyeon Taek · 문의: redtain0807@gmail.com

Threadscoupas는 사용자가 자신의 Threads 계정에 상품 소개 콘텐츠를 작성·예약·발행하고 성과를 확인하도록 돕는 개인용 데스크톱 도구입니다.

1. 수집·처리하는 정보

Threadscoupas는 서비스 작동에 필요한 범위에서 사용자가 직접 연결한 Threads 계정의 인증 정보, 계정 식별자, 작성·예약·발행한 게시물 정보, 게시물 인사이트(예: 조회·반응·클릭 관련 집계), 사용자가 입력하거나 자신의 브라우저에서 수집하도록 허용한 상품 정보와 이미지 주소를 처리합니다.

2. 정보의 이용 목적

처리한 정보는 Threads 콘텐츠의 작성·예약·발행, 사용자의 게시물 성과 확인, 중복 콘텐츠 방지, 그리고 사용자가 선택한 성과 기반 콘텐츠 개선에만 이용합니다. 공개 키워드 검색 권한이 승인되는 경우에도 공개 게시물의 문구를 복제하거나 재게시하지 않고, 공개 검색 결과의 순위·길이·문단 구조 같은 집계된 콘텐츠 특성만 보조적으로 분석합니다.

3. 저장 위치와 보유 기간

계정 연결 정보와 운영 데이터는 기본적으로 사용자의 Windows PC에 있는 Threadscoupas 로컬 데이터베이스와 설정 파일에 저장됩니다. 사용자가 연결한 공개 이미지 호스팅 저장소에는 게시물에 첨부하기 위해 선택한 이미지 파일만 저장될 수 있습니다. 운영자는 사용자의 인증 토큰이나 비밀번호를 별도 서버에 판매·공유·보관하지 않습니다. 사용자는 앱에서 계정 연결을 해제하거나 로컬 데이터 파일을 삭제해 언제든 보유 기간을 종료할 수 있습니다.

4. 제3자 제공 및 서비스 제공자

콘텐츠 발행과 인사이트 조회에는 Meta Threads API를 사용합니다. 사용자가 선택한 상품의 제휴 링크 생성에는 쿠팡파트너스의 공식 기능을 사용합니다. 사용자가 NVIDIA 생성 기능을 설정한 경우에만 상품 근거를 바탕으로 초안을 생성하기 위해 NVIDIA API를 사용합니다. 각 서비스의 처리는 해당 서비스의 약관과 개인정보처리방침을 따릅니다.

5. 보안

Threadscoupas는 사용자의 Threads 비밀번호를 수집하지 않습니다. 공식 OAuth 방식으로 받은 토큰은 로컬 PC에 저장되며, 사용자는 PC 접근 권한 관리와 운영체제 보안 업데이트를 유지해야 합니다. 어떤 인터넷 전송·저장 방식도 완전한 보안을 보장할 수는 없지만, 운영자는 필요한 범위를 넘는 정보 처리를 피합니다.

6. 이용자의 선택권과 삭제 요청

사용자는 언제든 계정 연결을 해제하고, 로컬 앱 데이터 또는 연결된 이미지 저장소의 본인 데이터를 삭제할 수 있습니다. 운영자에게 데이터 삭제 또는 관련 문의를 하려면 redtain0807@gmail.com으로 요청할 수 있습니다. 자세한 절차는 데이터 삭제 안내를 참조하세요.

7. 방침 변경

기능이나 관련 법령이 변경되면 이 방침을 업데이트할 수 있으며, 최신 버전은 이 페이지에 게시합니다.

Privacy Policy — English Summary

Threadscoupas is a personal desktop tool that helps users draft, schedule, publish and review content for Threads accounts they connect. It processes only the information needed for these functions, such as OAuth tokens, account identifiers, post content, post insights, and user-provided or user-authorized product information. Data is stored primarily on the user’s local Windows PC. It does not collect Threads passwords or sell user data. Users can disconnect accounts and delete local data at any time, or contact redtain0807@gmail.com for deletion requests. If public keyword search is approved, public results are used only to analyze aggregate content structure; posts are not copied or republished.
